
# Hand Gesture Recognition for Touchless Control (PS-49)

A deep-learning project that classifies hand gestures from near-infrared images using a Convolutional Neural Network (CNN). The project evaluates generalization to unseen people using **10-fold Leave-One-Subject-Out (LOSO) evaluation** on the LeapGestRecog dataset.

## Project Overview

- **Problem statement:** PS-49 — Hand Gesture Recognition for Touchless Control
- **Dataset:** LeapGestRecog
- **Framework:** TensorFlow / Keras
- **Model:** Custom CNN
- **Input:** Grayscale images resized to `256 × 96` pixels
- **Classes:** 10

## Dataset

The dataset inspection in this project found:

- **20,000 images**
- **10 subjects** (`00`–`09`)
- **10 gesture categories**
- **2,000 images per gesture** across the full dataset
- **2,000 images per subject**
- Original images are grayscale and `640 × 240` pixels

Images were resized to `256 × 96` and normalized to the `[0, 1]` range.

> The dataset is not included in this repository. Obtain it from the original Kaggle source and follow the dataset's applicable terms.

## Model Architecture

The CNN contains:

1. Convolution with 32 filters (`3 × 3`), batch normalization, ReLU, and max pooling
2. Convolution with 64 filters (`3 × 3`), batch normalization, ReLU, and max pooling
3. Convolution with 128 filters (`3 × 3`), batch normalization, ReLU, and max pooling
4. Convolution with 192 filters (`3 × 3`), batch normalization, ReLU, and max pooling
5. Global average pooling
6. Dense layer with 128 units and ReLU
7. Dropout (`0.4`)
8. Softmax output layer with 10 units

The model contains **341,290 parameters**. Training used Adam, sparse categorical cross-entropy, batch size 32, early stopping, and learning-rate reduction callbacks.

## Evaluation Method

The project used **10-fold Leave-One-Subject-Out (LOSO) evaluation**. Each fold holds one subject out for testing and uses a different subject for validation; the remaining eight subjects are used for training.

## Important Evaluation Limitation

An exact-duplicate audit found cross-subject duplicate images between subjects `02` and `05`, in the `08_palm_moved` category. These duplicates affect training/test separation in **folds 3 and 6** and may inflate their scores. The reported mean is from the original LOSO experiment; a duplicate-controlled sensitivity analysis has not been reported.

The confusion matrix was regenerated using the saved fold-10 model on subject `09` and reproduced **100.00% accuracy on 2,000 images**. This is a single-fold result, not the overall LOSO performance.

## Loading the Saved Model

After placing the model and class mapping at the paths below:

```python
import json
import tensorflow as tf

model = tf.keras.models.load_model("model/leap_gesture_cnn.keras")

with open("model/class_mapping.json", "r") as f:
    class_mapping = json.load(f)

print(class_mapping)
```

For inference, preprocess images as during training: decode as grayscale, resize to `(96, 256)` in height-width order, convert to `float32`, and divide pixel values by `255.0`. Add a batch dimension before prediction. Ensure the class-index mapping matches the saved model.

## Limitations and Future Work

- Performance varies across subjects; the lowest fold accuracy was 86.25%.
- Cross-subject duplicates affect two folds and warrant further investigation.
- Evaluation on one dataset does not establish real-world performance across different cameras, lighting conditions, backgrounds, or gesture styles.
- Future work includes duplicate-controlled evaluation, more independent subjects, per-class error analysis, and real-time camera testing.
